## 0. Mission & golden rules

**Mission.** Deliver the full detection-model stack and its MLOps spine: `L2` unsupervised UEBA (Isolation Forest + ECOD/COPOD + autoencoder + One-Class SVM, PyOD) with per-entity/per-peer/global baselines; `L3` supervised GBDT (LightGBM default + CatBoost + XGBoost) with TreeSHAP + isotonic calibration + imbalance handling; `L4` sequence (simple baselines FIRST, then USAD/TranAD/Anomaly-Transformer/DeepLog/LAXCAT) under honest non-point-adjust evaluation; `L5` graph (XGB-Graph/RF-Graph default, GraphSAGE, CARE-GNN/PC-GNN/BWGNN/GAT/HGT) with GNNExplainer; `L6` stacked-meta-learner fusion + calibration + reason-code assembly; explainability, drift monitoring, MLflow champion/challenger MLOps, active learning, fairness/bias tests, adversarial robustness, and the primary→secondary→deterministic LLM narrative gateway. Everything is **REAL** on synthetic + CERT/Elliptic data **except**: the live NEAR AI / Groq provider calls and TEE attestation verification (**SCAFFOLD** — code complete, needs real keys/hardware) and the independent model-validation sign-off (**MOCK** — simulated reviewer).

**Golden rules (restate to yourself every session — these are non-negotiable):**
1. **ALERT-ONLY.** Models score and explain; a human decides. **Never auto-block** money or auto-classify fraud. No model output triggers an action — it only ranks/explains. (blueprint Part 16 natural justice; Part 25.7)
2. **ON-PREM + SYNTHETIC ONLY.** No real PII, no real bank feeds, no real cloud creds. Train/evaluate on the synthetic simulator (DATA) + public benchmarks (CERT/Elliptic/IEEE-CIS). API keys are injected at runtime from a secrets manager — **never hardcode `NEAR_AI_API_KEY`/`GROQ_API_KEY`/`PII_HMAC_KEY`**. (Part 25 framing)
3. **VALIDATE AGAINST THE BLUEPRINT.** A task is "done" only when the cited blueprint Part's requirement is demonstrably met. Cite the Part in every commit and in your laptop log.
4. **NOTHING DROPPED.** Every task in §6 and every must-cover capability must be represented. If you find a blueprint requirement nobody owns, raise it in `CONTEXT.md` immediately.
5. **STAY IN YOUR LANE.** Edit only `ml/`, your own log `docs/laptops/02-ml.md`, append to shared `CONTEXT.md`/`TODO.md`. Never edit `BACKEND.md` (read-only for you) or another laptop's dirs.
6. **HONEST EVALUATION.** Never use point-adjust (PA) for time-series; always include simple baselines; always split by time; never claim deep-model SOTA without it beating baselines on *our* data. (Part 14, Part 20.4)

## 7. Detailed build instructions per milestone (blueprint specifics — nothing lost)

> These spell out the models, hyperparameters, feature lists, typologies, and schemas so nothing is ambiguous. Always cross-check against the cited Part.

### 7.1 The evaluation harness (ML-2) — get this right FIRST (Part 14, Part 20.0/20.4)
- **Metrics:** PR-AUC / average precision; precision@k; alert-to-true-fraud ratio; recall on known historical cases; time-to-detection reduction. For sequence/time-series: **range-aware / affiliation-aware PR** and **VUS-PR**. **Never ROC-AUC alone** (flatters imbalance).
- **NEVER point-adjust.** PA can make random scores look SOTA (Kim'22, Wu&Keogh). Build the harness so PA is impossible to select; always include simple baselines in every comparison table.
- **Splits:** time-based (past→future) only — never random; entity-disjoint validation. Provide a leaky-feature detector (e.g., reject features perfectly correlated with the label / future-derived). Add a **synthetic-only-evaluation guard** that warns that synthetic validates training/augmentation but detection quality must be confirmed on real labels (we only have synthetic, so the guard documents this limitation).

### 7.2 L2 unsupervised (ML-3, ML-15-L2) — Part 7/L2, Part 20.2, Part 22.2
- **Isolation Forest (primary/cold-start):** `n_estimators=150`, `max_samples=256` (ψ=256), `max_features=1.0`, `contamination='auto'` or expected anomaly rate; score = average path length.
- **ECOD / COPOD:** parameter-free (PyOD, use as-is) — auditable, reproducible.
- **Autoencoder:** symmetric MLP, bottleneck ≈ ¼–½ input dim, ReLU, dropout 0.1–0.3, MSE loss, early stopping; flag when reconstruction error > 99th percentile of the normal-behaviour distribution; emit **per-feature reconstruction-error explanation**.
- **One-Class SVM:** smaller-scale detector.
- **Ensemble:** run 2–3 detectors and **fuse** scores. Library = **PyOD** (consistent API).
- **Training (Part 22.2):** fit on a window of **normal** behaviour, **per-entity and per-peer-group** with **time decay**; persist baselines + thresholds; scheduled refresh; **low-and-slow poisoning guard** = peer-anchoring + change-point checks.

### 7.3 L3 supervised GBDT (ML-4, ML-15-L3) — Part 7/L3, Part 20.3, Part 22.2
- **LightGBM (production default):** `objective=binary`, `metric=average_precision/auc`, `num_leaves=31→255`, `max_depth=-1` (or 6–12), `learning_rate=0.02–0.05`, `n_estimators=1000–3000` **with early stopping**, `feature_fraction=0.8`, `bagging_fraction=0.8`, `bagging_freq=1`, `min_child_samples=50–200`, **`is_unbalance=true` or `scale_pos_weight=neg/pos`**.
- **XGBoost (robust baseline):** `tree_method=hist`, `max_depth=4–8`, `eta=0.01–0.05`, `subsample=0.8`, `colsample_bytree=0.8`, `min_child_weight≥5`, `scale_pos_weight=neg/pos`, `eval_metric=aucpr`, early stopping.
- **CatBoost (high-cardinality categoricals/imbalance):** `depth=6–10`, `learning_rate=0.03–0.1`, `l2_leaf_reg=3–10`, `auto_class_weights=Balanced`, native `cat_features` for ID-like columns.
- **Imbalance:** negative subsampling **1:3–1:10**, class weights / focal loss, then **calibrate (isotonic/Platt)** so 0–100 is meaningful. **Split by time, never randomly.**
- **Benchmark all three**, pick per metric+latency. **Do not** reach for TabNet/FT-Transformer as primary.
- **TreeSHAP** for live reason codes (exact, fast); **SHAP interaction values offline only** (quadratic — too slow online).

### 7.4 L4 sequence (ML-5, ML-15-L4) — Part 7/L4, Part 20.4, Part 22.2 — **the warning layer**
- **Simple baselines FIRST:** windowed PCA, windowed Isolation Forest (window 10–60 events or a session), matrix-profile/one-liners, small LSTM-/conv-AE.
- **Deep candidates (only if they beat baselines under honest eval):** **USAD** (adversarial autoencoders, fast/stable), **TranAD** (transformer, focus-score self-conditioning + adversarial; window ≈10–100 steps, small latent dim), **Anomaly-Transformer**, **Deep Isolation Forest**, **DeepLog/LogAnomaly** (log-sequence next-event for privileged-session/DB logs).
- **LAXCAT (supervised explainer):** CNN feature extraction + **variable-attention** + **temporal-attention** → tells *which variables* and *which time intervals* drove the classification. Use to explain flagged sessions once you have labels (EDD). It is an enhancement, not a cold-start detector.
- **Evaluation:** range/affiliation-aware PR or VUS-PR, **never PA**; include baselines; split by time; keep deep inference batched off the hot path.

### 7.5 L5 graph (ML-6, ML-15-L5) — Part 7/L5, Part 20.5, Part 22.2
- **XGB-Graph / RF-Graph (default):** per-node **k-hop aggregates** (mean/sum/max of neighbor features, degree, centrality, shared-attribute counts) for **k=1–2** → GBDT (params as §7.3). 0→2 hops improves results (GADBench).
- **GraphSAGE (inductive, for new streaming nodes):** 2 layers, hidden 128–256, **mean** aggregator, neighbor sample ≈[25,10], dropout 0.5, lr 0.01, Adam; class weighting/focal loss for imbalance.
- **Camouflage-resistant specialized GNNs:** CARE-GNN, PC-GNN, BWGNN, GAT, heterogeneous HGT/GoSage — for hard collusion/heterophily cases (use authors' reference configs as starting points; they need tuning). Libraries: **PyTorch Geometric / DGL**; **PyGOD** for graph outliers.
- **Graph construction/maintenance:** nodes = employees, accounts, beneficiaries, devices, vendors; edges = transactions/access/shared-attributes (typed); **incremental refresh**. **GNNExplainer**-style attribution for regulator-facing reasons.
- **GADBench 0→2-hop ablation harness** to prove the aggregation lift.

### 7.6 L6 fusion (ML-7, ML-15-L6) — Part 7/L6, Part 20.7, Part 22.2
- **Stacked meta-model** = logistic regression or shallow LightGBM over the **per-layer scores + rule flags** (transparent, auditable).
- **Calibrate** with isotonic regression so 0–100 maps to real fraud probability (threshold is set against analyst capacity → calibration is operationally required).
- **Reason-code assembler:** rule provenance + SHAP top features + attention/graph evidence, output in the `BACKEND.md` §2 shape. One alert per entity (fusion reduces alert fatigue).
- **Seam reminder:** the *online* fusion service is BACKEND (Part 18). You ship the **artifact** (meta-learner + calibrator) + the offline reason-code assembler. Publish the artifact contract in `CONTEXT.md`.

### 7.7 Explainability cross-cutting (ML-4/ML-6/ML-7) — Part 20.6
- **TreeSHAP** for live GBDT reason codes (exact, fast, no sampling noise). **Counterfactuals (DiCE/Alibi)** for actionable recourse ("had export volume been below X, no flag"). **Rule provenance** for the deterministic layer. **LAXCAT attention** for sessions. **SHAP interaction values → offline/regulatory docs only.** Treat explanations as defense-in-depth — never the sole basis (they can be adversarially manipulated, §7.13).

### 7.8 Shared learning strategies (ML-8) — Part 5.3/5.4/5.5
- **Transfer learning:** pretrain sequence/graph encoders on **CERT** (insider) / **Elliptic** (graph), fine-tune on own data.
- **PU / semi-supervised:** learn from the unlabeled majority.
- **Imbalance:** subsampling 1:3–1:10 + class weights/focal loss + **post-hoc calibration**.
