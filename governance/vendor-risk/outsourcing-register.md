## 4. Aggregate concentration-risk assessment

| Dimension | Finding |
|---|---|
| Infrastructure concentration | Single cloud (AWS) for the pilot, but **structurally exitable** — all-open-source/self-hostable stack, Terraform `target = aws \| onprem \| lightsail`, component-swap map (Part 26.4). Production target is on-prem in-India. |
| LLM concentration | **Multi-provider** (NEAR AI primary, Groq secondary) **plus** a deterministic template fallback **plus** an on-prem `gpt-oss-120b` migration path — no single LLM vendor is a single point of failure. The LLM is also **off the scoring/decision path** (narrative-only). |
| Cross-vendor systemic risk | The only external egress is the **tokenized, TEE-protected** LLM traffic to the two allow-listed endpoints; everything else has no internet egress (Part 26.2). |
| **Overall residual concentration risk** | **Low** — mitigated by migration readiness, multi-provider LLM design, template fallback, and the ALERT-ONLY / off-critical-path posture of the LLM. |
